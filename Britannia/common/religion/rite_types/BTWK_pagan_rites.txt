###############################
# Mainline rite types         #
###############################
# One rite per faith that would otherwise only ever have an engine-generated
# dynamic rite. Dynamic rites get positional tags (dynamic_rite_%i) that script,
# history and localisation cannot reference, so every faith gets a stable
# scripted main rite instead.
# Keys, and therefore names, adjectives and adherent locs, match the parent
# faith so the player-facing text is unchanged.
# color, tenets, doctrines and tenet_selection_pair are copied from the faith
# type: an empty tenets block on a rite falls back to the religion's core
# tenets rather than the faith's, which would silently drop faith tenets.
